# Premier
 Premier Nehpro is a comprehensive management system designed for healthcare providers, especially dialysis and nephrology centers. The platform streamlines administrative and financial workflows by offering tools for PhilHealth payment tracking, patient management, and copay handling. It also includes robust report generation features that help monitor performance, compliance, and revenue.

### Key Features
- PhilHealth Payment Tracking – Monitor claims, payments, and benefit utilization.
- Report Generation – Generate financial, operational, and patient-related reports.
- Copay Management – Automate computation and recording of patient copays.
- Patient Management – Maintain patient profiles, sessions, and billing information.
- Daily Census
